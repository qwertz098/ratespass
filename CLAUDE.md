# Projektkonventionen (Ratespaß)

- **Fragen: Sprache ≠ Region.** Englisch bildet *internationales/globales* Wissen ab. Neue Fragen bekommen `region: "global"` (Standard, in de+en) oder `"dach"` (nur deutschsprachig relevant, reicht mit deutscher Fassung). Zweifelsfall-Test: Würde man es in London/New York/Delhi erkennen? Details: `docs/QUESTIONS.md` → „Regionen“.
- **Neue Batches** (`batches/original-NNN.json`, je 200 Fragen): Format und Prüfregeln in `docs/QUESTIONS.md`; nach dem Schreiben `npm test` (prüft Format, Lizenz, Dubletten, Region-Konsistenz, ausreichend globale Fragen je Kategorie), README-Zähler anpassen, committen und auf den Entwicklungsbranch pushen.
- **Kategorie-Stufen:** Kategorien haben eine Stufe (`basic`/`nerd`/`expert`, `CATEGORY_TIERS` in `server/categories.ts`); jeder Spieler wählt Level und Extra-Kategorien selbst; im Duell zählt die niedrigste Einstellung (`server/settings.ts`). Neue Kategorie = Eintrag dort + `cat.*` in `web/i18n.js` (de+en) + Farbe in `web/style.css` + mind. 40 Fragen je Sprache; Details in `docs/QUESTIONS.md`.
- **Datenschutz:** Verantwortlichen-Angaben kommen aus Env (`CONTROLLER_*`), der vorbereitete Text liegt in `legal/datenschutz.{de,en}.md` (gerendert von `server/privacy.ts`); jede Änderung am Text oder an einer Funktion, die Daten betrifft, ändert die Version und löst eine einmalige erneute Zustimmung aus (bewusst). Neue Datenfelder/Funktionen dort beschreiben, Details `docs/DATENSCHUTZ.md`.
- **Echtzeit (Live-Spielabend):** nur Einzelinstanz; Reverse-Proxys dürfen `/api/live/*/events` nicht puffern (Caddyfile `flush_interval -1`). Neue Antwortquellen müssen in `ANSWER_SOURCES` (`server/leaderboard.ts`) und `server/stats.ts` auftauchen.
- **Korrekturen im Admin** (Moderation/Überarbeitung) werden in `edits` protokolliert und per `npm run apply:edits` in die Batch-Dateien übernommen – die Batch-Dateien sind die Quelle der Wahrheit.
- **Admin-Token nie im Chat/Code**: nur über `ADMIN_TOKEN` in der Umgebung.
- Tests: `npm test` (Node ≥ 26, keine Laufzeit-Abhängigkeiten); Typen: `npm run check`.
